# Implementation of a basic WebAR scenario using \<model-viewer>
## \~ What is this project about? ~
The WebAR scenario with web-component \<model-viewer> allows depicting a kerosene lamp on the real surface. It is possible to change the model by editing the code to demonstrate any other object.
## \~ What technologies were used? ~
-	HTML
-	CSS
-	\<model-viewer>

# Реализация базового WebAR-сценария с использованием \<model-viewer>
## О чём проект?
WebAR-сценарий с использованием веб-компонента \<model-viewer> позволяет отобразить керосиновую лампу на реальной поверхности. Возможна замена модели путём редактирования кода для демонстрации любого другого объекта.
## Какие технологии были задействованы?
-	HTML
-	CSS
-	\<model-viewer>
